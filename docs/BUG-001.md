# BUG-001 : Formulaire de contact : le label Message n’est pas associé à son champ

| Champ         | Valeur                                                                                            |
| ------------- | ------------------------------------------------------------------------------------------------- |
| Identifiant   | BUG-001                                                                                           |
| Date          | 28/10/2026                                                                                        |
| Environnement | [automationintesting.online](https://automationintesting.online/), Chrome (Version 156 (64 bits)) |
| Gravité      | Mineure (impact accessibilité)                                                                   |
| Statut        | Ouvert, contourné dans les tests                                                                 |

## Étapes de reproduction

1. Ouvrir la page [automationintesting.online](https://automationintesting.online)
2. Descendre jusqu'au formulaire "Send Us a Message"
3. Cliquer sur le mot "message" au-dessus de la zone de texte
4. Constater que le curseur ne se place pas dans le champ, à comparer en cliquant sur "Subject" qui lui place bien le curseur
5. Faire un clic droit sur la zone de texte puis sur "inspecter" pour voir les attributs

## Résultat attendu

L'attribut for du label correspond à l'id du champ et un clic sur le label place le curseur dans le champ

## Résultat obtenu

Le clic sur le label ne place pas le curseur dans le champ

Le label a l'attribut for="message", alors que la zone de texte a id="description"

## Impact

Utilisateur de lecteur d'écran, un lecteur d'écran annonce une zone de texte sans nom, l'utilisateur ne sait pas ce qu'il doit saisir. Le clic sur le label ne fonctionne pas non plus, ce qui gêne aussi les personnes qui ont du mal à viser une petite zone

## Comment il a été détecté

Le test automatisé UI-02 ne trouvait pas le champ avec getByLabel('Message').
Contournement : getByTestId('ContactDescription') dans pages/ContactForm.ts.
