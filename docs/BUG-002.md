# BUG-002 : Formulaire de contact : les messages d'erreur ne sont pas annoncés aux lecteurs d'écran

| Champ         | Valeur                                                                                            |
| ------------- | ------------------------------------------------------------------------------------------------- |
| Identifiant   | BUG-002                                                                                           |
| Date          | 30/10/2026                                                                                        |
| Environnement | [automationintesting.online](https://automationintesting.online/), Chrome (Version 156 (64 bits)) |
| Gravité      | Mineure (impact accessibilité)                                                                   |
| Statut        | Ouvert, contourné dans les tests                                                                 |

## Étapes de reproduction

1. Ouvrir la page [automationintesting.online](https://automationintesting.online)
2. Descendre jusqu'au formulaire "Send Us a Message"
3. Cliquer sur Submit sans rien remplir, puis attendre l'affichage du bloc rouge (quelques secondes)
4. Faire un clic droit sur le bloc rouge puis sur "inspecter" pour voir les attributs
5. Dans les outils de développement, onglet Accessibility (à droite de styles, parfois caché derrière >>) : la ligne role indique 'generic', alors qu'on attend 'alert'

## Résultat attendu

Le bloc d'erreur a l'attribut role="alert".

L'onglet d'accessibility doit indiquer Role alert, ce qui permet à un lecteur d'écran d'annoncer les erreurs dès leur apparition.

## Résultat obtenu

role = generic

```html
<div class="alert alert-danger" style="margin-bottom: 5rem;">
```

Il n'y a ni le 'role' et ni le 'aria-live'

## Impact

Utilisateur de lecteur d'écran, un lecteur d'écran n'annonce pas les erreurs à un utilisateur malvoyant, il peut croire que sont message est parti.

Gravité mineure : aucun impact pour les utilisateurs voyants, mais pas de contournement possible pour un utilisateur de lecteur d'écran.

Il y a un écart au WCAG 2.1, critère 4.1.3 (Messages d'état, niveau AA), repris par le critère 7.5 du RGAA.

## Comment il a été détecté

Les tests automatisés UI-03 et UI-04 ne trouvaient pas getByRole("alert").
Contournement : page.locator('.alert-danger') dans pages/ContactForm.ts.
